## 1. 这个算法解决什么问题

**输入**：一张普通光学图像（无人机照片/卫星光学图，通常是海面上的舰船）。

**输出**：一张具有真实 SAR（合成孔径雷达）观感的灰度图像——相干斑颗粒、点目标十字旁瓣、海面杂波噪底、40dB 动态范围。

**定位（重要）**：这是**模板驱动的正演仿真**，不是从真实 SAR 回波重建：

- 光学图像提供"目标的几何形状与散射强度分布"模板（亮的地方=强散射体）；
- 算法用 SAR 的物理模型（回波方程 + RDA 成像）把这张模板"重新观测"一遍；
- 因此输出的纹理/几何与光学图一致，但具备真实 SAR 的辐射与统计特性。

> ⚠️ 免责声明：该输出是仿真近似，**不能**当作真实相干 SAR 观测数据使用。

与旧版算法（显著性+概率撒点）的本质区别：旧版直接在图像域"画"斑点，**没有任何雷达物理**；本版走完整的"散射点 → 回波 → 成像"正演链路，斑点、旁瓣、杂波都是成像过程的自然产物，因此换雷达参数（分辨率、波段、视角）结果会物理一致地变化。

## 3. SAR 成像基础理论

### 3.1 成像几何

正侧视条带 SAR（Stripmap）的经典几何：

- 载机/卫星沿直线以速度 $v$ 匀速飞行，高度 $H_c$；
- 天线波束指向侧下方，**侧视角** $\theta_{SL}$（俯角）、**斜视角** $\theta_{SQ}$（偏离正交视线的角度）；
- 场景中心斜距 $R_c = \dfrac{H_c}{\cos\theta_{SQ}\cdot\cos\theta_{SL}}$。

波束中心打到地面的位置（这是 `place_scene_at_beam` 平移的目标点）：

$$x_c = \frac{H_c}{\cos\theta_{SL}}\tan\theta_{SQ}, \qquad y_c = H_c\tan\theta_{SL}$$

天线波束宽度由天线孔径决定（矩形口径的瑞利近似，0.886 是 sinc 主瓣半功率因子）：

$$\theta_{az} = 0.886\frac{\lambda}{D_{az}}, \qquad \theta_{rg} = 0.886\frac{\lambda}{D_{rg}}, \qquad \lambda = \frac{c}{f_0}$$

**合成孔径长度**（目标被照射期间平台走过的距离）：

$$L_{SAR} = \frac{R_c \cdot \theta_{az}}{\cos\theta_{SQ}}$$

合成孔径原理一句话：目标在波束内停留期间，其回波相位 $\exp(-j4\pi R(\eta)/\lambda)$ 随慢时间 $\eta$ 呈线性调频（多普勒历史），把这个"多普勒调频信号"做匹配滤波，就能聚焦出 $\rho_a = D_{az}/2$ 的方位分辨率——**与距离无关，只有真实孔径的一半量级**。

### 3.2 距离向：线性调频与脉冲压缩

发射信号为 LFM chirp：

$$s_t(t) = \mathrm{rect}\left(\frac{t}{T}\right)\exp\left(j\pi k_r t^2\right), \qquad k_r = \frac{B_r}{T}$$

- $T$：脉宽；$B_r$：带宽；$k_r$：调频率。
- 回波是发射波形的延迟副本，延迟 $\tau = 2R/c$。
- **匹配滤波**（频域实现）：

$$H_r(f_r) = \exp\left(j\pi \frac{f_r^2}{k_r}\right)$$

- 压缩后分辨率：$\rho_r = \dfrac{c}{2B_r}$（默认参数 80MHz 带宽 → 1.87m）。

### 3.3 回波模型（点散射 + 停-走假设）

第 $i$ 个脉冲、第 $m$ 个散射点的回波：

$$s_i(t) = \sigma_m \cdot \exp\left(-j\frac{4\pi R_{im}}{\lambda}\right)\cdot \exp\left(j\pi k_r \left(t-\frac{2R_{im}}{c}\right)^2\right)$$

- $\exp(-j4\pi R/\lambda)$：**相位历史**，斜距 $R_{im}$ 双曲线变化 → 方位多普勒的来源；
- "停-走"假设：脉冲传播期间平台不动（$c \gg v$，完全成立）；
- 实现：每个散射点生成一段 chirp 片段，按延迟 $\text{delay} = \lfloor (2R/c - t_{Rmin}) f_s \rceil$ 累加进回波矩阵。

斜距双曲线（方位聚焦与 RCM 的共同根源）：

$$R(\eta) = \sqrt{R_c^2 + v^2\eta^2 - 2 R_c v \eta \sin\theta_{SQ}}$$

### 3.4 方位向：多普勒

对相位历史求瞬时频率：

$$f_D(\eta) = -\frac{2}{\lambda}\frac{dR(\eta)}{d\eta}\Big|_{\eta=0} = \frac{2v\sin\theta_{SQ}}{\lambda} - \frac{2v^2\cos^2\theta_{SQ}}{\lambda R_c}\eta = f_{DC} + k_a \eta$$

- **多普勒中心** $f_{DC} = \dfrac{2v\sin\theta_{SQ}}{\lambda}$（斜视角不为 0 时频谱居中偏移）；
- **方位调频率** $k_a = \dfrac{2v^2\cos^2\theta_{SQ}}{\lambda R_c}$；
- **多普勒带宽** $B_d = \dfrac{2v\theta_{az}}{\lambda}$ → PRF 必须 $\ge B_d$（否则方位混叠，代码会告警）；
- 方位匹配滤波器：$H_a(f_a) = \exp\left(j\dfrac{4\pi R_0 \cdot \mathrm{RCMF}(f_a)}{\lambda}\right)$。

## 4. 目标提取：从光学图到目标掩码

### 4.1 灰度化

ITU-R 601 加权（`to_gray`）：

$$I = 0.2989 R + 0.5870 G + 0.1140 B$$

### 4.2 Otsu 自动阈值（`otsu_threshold`）

Otsu(1979) 最大类间方差法：遍历阈值 $t$，把像素分为前景/背景两类，类间方差

$$\sigma_b^2(t) = w_0(t)\,w_1(t)\,\left[\mu_0(t)-\mu_1(t)\right]^2$$

使 $\sigma_b^2$ 最大的 $t$ 即最优阈值（类间分得越开 → 类内越紧）。实现用 256-bin 直方图 + 累积和一次扫描。

代码细节：实际阈值 = `max(0.12, Otsu × 0.95)`——乘 0.95 略放宽，防止把弱散射的舰体边缘切掉。

### 4.3 亮/暗双极性自动选择（`segment_auto`）

海面场景有两种典型情况：舰体比海面**亮**（常规）或**暗**（烈日反光）。auto 模式两种极性各做一遍 `Otsu → 连通域 → 评分`，取评分高者：

- 亮极性信号 = 灰度；暗极性信号 = 255 − 灰度；
- 结果记录 `polarity`（后续点云幅度跟随该极性的信号图）。

### 4.4 连通域评分（`_score_component` / `_best_mask`）

阈值掩码往往包含杂块，需要挑出"最像舰船"的一块。对每个连通域（`scipy.ndimage.label`，取面积前 12 的候选）打分：

$$\text{score} = 2.2\,\underbrace{e^{-\left(\frac{\log_{10}(r)+1.25}{1.3}\right)^2}}_{\text{面积占比偏好}} + 1.1\,\underbrace{\text{居中度}}_{\text{离图像中心}} + 0.5\,\underbrace{\text{填充率}}_{\text{面积}/外接框} - 3.0\,\underbrace{\text{边界接触率}}_{\text{贴边惩罚}}$$

面积占比 $r$ 的对数高斯偏好峰值在 $r \approx 5.6\%$（对应舰船在场景中的典型占比）；占比 <0.03% 或 >72% 直接判 -100；贴边的块（码头/暗角）重罚。

### 4.5 外部掩码（YOLO）接入（`load_external_mask`）

前端用自训练的舰船 YOLO 权重检测出旋转框/实例掩码/水平框 → 光栅化成 bool 掩码 → 直接传入 `mask=` 参数，跳过内置分割。**权重调用约定与旧系统一致**：默认路径 `<脚本上级>/optical2sar/weights/optyolo/best.pt`，替换文件即换模型（详见 README）。

## 5. 掩码 → 散射点云

`_auto_step` + `mask_to_points`：

1. **抽稀**：步长 `step`（不指定时从 1 逐步加倍，直到点数 ≤ 30000——控制后续回波仿真耗时）；
2. **坐标换算**：掩码内像素 $(row, col)$ → 地面坐标 $x = col \cdot step \cdot p_x$，$y = row \cdot step \cdot p_y$，并减去均值**居中**；
3. **幅度**：$\sigma = $ 极性信号图的灰度值（0-255），并做下限截断：正幅度的 5% 分位数 × 0.1（避免零幅度点，保持弱散射的相对关系）；
4. 输出点云 $P \in \mathbb{R}^{N\times 4}$，列 = `[方位x, 地距y, z=0, 幅度σ]`。

> 模板驱动假设：掩码内每个抽样像素 = 一个点散射体，其后向散射系数正比于光学灰度。

## 7. RDA 成像逐步推导（代码核心）

RDA（Range Doppler Algorithm，距离多普勒算法）是 SAR 成像最经典的算法。`rda_numpy` 的五个阶段与公式一一对应：

### 步骤 0：回波正演（§3.3 模型）

```python
pulse = amp[vis_idx] * exp(-j*4π*R/lam)      # 相位历史
pulse = pulse * chirp                         # exp(jπ·kr·t²)
np.add.at(echo[i], col, pulse)                # 按延迟累加 → echo (Na×Nr)
```

### 步骤 1：距离压缩 + 距离走动校正 → RWC

斜视角使回波包络随慢时间线性平移（走动，$\Delta R = v\sin\theta_{SQ}\cdot\eta$），在二维频域乘一个线性相位校正：

$$H_{sl} = \exp\left(-j\frac{4\pi}{c}\cdot\frac{f_{DC}}{2}\,\tau_a\,(f_0+f_r)\right), \qquad \text{RWC} = \text{IFFT}_{r}\left[\text{FFT}_{r}(\text{echo})\cdot H_{sl}\right]$$

### 步骤 2：二维频域 → RGC（距离压缩精化 + SRC）

定义**距离徙动因子**（双曲线斜距的频域表达，RCMC 和 SRC 都建立在它上面）：

$$\mathrm{RCMF}(f_a) = \sqrt{1 - \frac{\lambda^2 f_a^2}{4 v_{xa}^2}} = \frac{R_c}{R(f_a)}$$

**二次距离压缩（SRC）**：大带宽×大斜视角时，距离脉冲响应随多普勒频率散开（距离-方位二次耦合），补偿滤波器：

$$K_{src} = \frac{2 v_{xa}^2 f_0^3\,\mathrm{RCMF}^3}{c\,R_0\,f_a^2}, \qquad H_{src} = \exp\left(-j\pi\frac{f_r^2}{K_{src}}\right)$$

（$f_a=0$ 处 $K_{src}\to\infty$，$H_{src}\to 1$，即无需补偿——代码里用 `np.inf` 自然处理。）

二维频域谱：`spec = FFT2(RWC) · Hsrc · Hr`，其中 $H_r$ 是距离匹配滤波（§3.2）。`RGC = IFFT2(spec)`。

### 步骤 3：距离徙动校正（RCMC）→ RMC

多普勒 $f_a$ 处散射点斜距 $R(f_a) = R_c/\mathrm{RCMF}(f_a)$。把"弯曲"的距离包络沿快时间拉直，等价于距离频域的线性相位：

$$H_{rcmc} = \exp\left(j\frac{4\pi f_r}{c}\left(\frac{R_c}{\mathrm{RCMF}(f_a)} - R_c\right)\right), \qquad \text{RMC} = \text{IFFT2}(\text{spec}\cdot H_{rcmc})$$

### 步骤 4：方位压缩 → Im

方位匹配滤波（多普勒调频斜率的共轭）：

$$H_a = \exp\left(j\frac{4\pi R_0\,\mathrm{RCMF}(f_a)}{\lambda}\right), \qquad \text{Im} = \text{IFFT}_{a}\left[\text{IFFT}_{r}(\text{focus\_spec})\cdot H_a\right]$$

其中 `focus_spec = spec_rcmc`（经 RCMC 的谱，与部署系统一致）。

**输出 Im 的方向**：行 = 方位（对应光学图的**列**），列 = 斜距（对应光学图的**行**）——即 Im 是光学布局的转置，显示层会转回来。

> `rda_numpy_enhanced` 是同一流程 + 真实感增强（§8），两条路径在增强全关时结果一致。

## 8. 真实感增强

### 8.1 相干斑（speckle）

真实 SAR 是**相干**成像：一个分辨单元内多个子散射体相干叠加，等效为每个散射点一个均匀随机初相 $\phi_0 \sim U[0, 2\pi)$：

$$\text{pulse} = \sigma \cdot e^{-j4\pi R/\lambda + j\phi_0}\cdot\text{chirp}$$

聚焦后幅度呈 Rayleigh 起伏的颗粒状纹理——单视 SAR 的标志性外观。`speckle_phase_strength<1` 时初相以零为中心收缩（弱化斑纹）。

### 8.2 K 分布海杂波（`generate_sea_clutter`）

低擦地角海杂波的经典复合模型：

$$A = \underbrace{\sqrt{\Gamma(k, 1/k)}}_{\text{纹理（涌浪起伏）}} \times \underbrace{\sqrt{\frac{n_1^2+n_2^2}{2}}}_{\text{散斑（Rayleigh）}} \times \underbrace{g_{near\to far}(r)}_{\text{距离增益梯度}} \times \underbrace{\sigma_{ref}\cdot s}_{\text{电平标定}}$$

- Gamma 纹理（均值归一，shape=k）建模海面大尺度起伏，k 越小尖峰越多；
- Rayleigh 分量是单元内相干干涉的结果；
- 杂波点铺满目标包围盒外扩 `clutter_margin` 倍的区域（格网步长 = 分辨率的一半），与目标点**一起进入 RDA 成像**——因此杂波会经历同样的聚焦过程，形成真实的杂波带而非贴图。

### 8.3 热噪声

复高斯 $n \sim \mathcal{CN}(0, \sigma^2)$，按**压缩前 SNR** 相对回波平均功率标定，成像后自然形成噪底。

### 8.4 加窗

矩形谱脉冲压缩旁瓣 -13.2dB，点目标呈"十字"旁瓣。距离/方位频域乘 Hamming（旁瓣约 -43dB，主瓣展宽 ~1.47 倍）/ Blackman / Kaiser(β) 窗抑制旁瓣。注意窗要 `ifftshift` 对齐到 FFT 的 DC 在首位（`correct_window_frequency_order=True`）。

### 8.5 慢时间误差（可选）

- 相位噪声：AR(1) 相关序列（相关系数 ρ，标准差按度）；
- 位置误差 / 速度漂移：$-4\pi \Delta R/\lambda$ 相位注入；
- 定时抖动：距离频域的随机相位斜坡。

## 9. 显示与输出

- **线性归一化**（`normalize_im`）：$|Im|$ min-max → [0,1]。问题：最亮单点会压黑全图。
- **dB 显示**（`normalize_im_db`，默认）：$20\log_{10}(|Im|/\max)$ 截断到 [-40dB, 0] 再线性映射——真实 SAR 图像的标准观察方式。
- 输出前转置（`.T`）使图像与输入同朝向（水平=方位向，竖直=地距向）。
- 可选 `destripe`：显示层竖条纹抑制（列中值背景扣除，只动显示图不动复数 Im）。

返回字典关键内容：`sar`（显示图）、`linear`（线性图）、`mask`（掩码）、`points`（点云）、`metadata`（雷达派生量 λ/ρr/ρa/合成孔径/多普勒带宽、告警、耗时等）。

## 10. 随机性与逐位复现

所有随机量走显式种子的 `np.random.default_rng`：

| RNG | 种子 | 用途 |
|---|---|---|
| 杂波生成 | `seed + 101` | Gamma 纹理、Rayleigh 散斑 |
| 增强成像 | `seed` | 斑点初相、相位噪声、位置误差、抖动、热噪声 |

确定性路径（`realism="clean"`）完全无随机。**相同参数 + 相同 numpy 版本 → 逐位一致**；与部署系统（SAR_ISAR演示系统.exe v2.2.2）已做过逐位对比验证。

## 13. 常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `No scatter point falls inside the antenna beam` | 场景没放进波束 | 确认走 `place_scene_at_beam`（顶层函数已自动处理） |
| 结果全黑 | 掩码为空 / 最亮点压黑 | 换 `polarity`/`threshold`；用默认 40dB 显示而非线性 |
| 警告"PRF低于估算多普勒带宽" | PRF 不足方位采样 | 提高 PRF 或减小 vx/增大 D_az |
| 速度慢 | 点数多 / 图大 | 增大 `step` 或用自动抽稀（默认 ≤30000 点） |
| 图像方向不对 | Im 原生是转置 | 顶层函数已自动转置；直接用复数 Im 时注意 |
